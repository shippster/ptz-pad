TriCaster setup

Add a camera

Add your first camera to start driving it with the controller.

Video for auto-tracking

If the camera needs a login, put it in the address: rtsp://user:password@192.168.1.50/2. A low-resolution second stream is lighter on the computer and tracks just as well. Ports and paths vary, so check the camera’s streaming settings.

Custom URLs

Paths start with / or give a full URL. Use {pan} {tilt} {zoom} {focus} (−100 to 100), {pspeed} {tspeed} {zspeed} {fspeed} (0 to 100), {dir} (left, rightup…), {zdir} (in, out), {fdir} (far, near) and {n} for the preset number.

These change the controller only; auto-tracking isn\u2019t affected by them (it finds the right direction itself). Ceiling-mounted camera? Most reverse their own controls when you turn on their Image Flip setting; if yours doesn\u2019t, tick both.

Two camera operators

Turn it onChoose 3. Two camera operators at the top, then press any button on each controller. Each drives its own camera at the same moment; neither waits for the other.
Same layoutSticks, triggers, presets, precision (RB), speed (D-pad up / down), focus, auto-track and lock work the same on each controller’s camera. Preview, cut, auto and Go live are off.
D-pad left / rightPicks that controller’s camera. It skips the camera the other controller has.
Xbox buttonDoes nothing on controller 2. The pop-up camera belongs to controller 1.
Wrong controller?Click Swap 1 and 2 in the Controller 2 bar. Buzz it rumbles controller 2.

No controller? Use WASD or arrows to move (Shift for full speed), E/Q zoom, R/F focus, 1–8 presets (Alt to save), H home, -/= tracking fine tune, T auto-track, L lock on speaker, Enter go live, P preview on TriCaster, C cut (Shift+C auto), [ ] switch camera.

Getting started
  1. Use Chrome or Edge. Pair the Xbox controller over USB or Bluetooth, then press any button with this page in front.
  2. For VISCA cameras, or any camera that needs a login, run node ptz-bridge.js in the folder with these two files and open http://localhost:8787.
  3. HTTP cameras without a login work straight from the browser. If the camera asks for a password, log in to its web page once in this browser, or send through the bridge.
  4. For NDI cameras, install NDI Tools (free from ndi.video) on this computer, then run the bridge.
  5. If the browser asks to allow access to devices on your local network, choose Allow.
  6. Not sure which protocol? Look for “VISCA over IP” in the camera’s network settings first. It is the most widely supported.
